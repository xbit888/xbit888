# XBIT888

Live-трекер покупок/продаж токена по контракт-адресу (CA). Тёмный интерфейс в стиле трейдинг-терминалов, с переключением языка (RU / EN / 中文).

## Возможности

- Определяет сеть и источник данных автоматически по CA: pump.fun (bonding curve), обычные DEX-пулы (Raydium/Orca/Uniswap V2-V3), Uniswap V4 (в т.ч. сеть Robinhood)
- Живая лента сделок: время, тип (BUY/SELL), кошелёк, сумма в токенах и в валюте пары
- MCAP в долларах, пересчитывается живьём с каждой сделкой
- График цены, статистика сессии (объём покупок/продаж, чистый поток)
- Двойной клик по кошельку — копирует адрес, по транзакции — открывает в обозревателе блоков
- Работает только с публичными бесплатными источниками данных, без ключей и кошельков

## Запуск

Требуется Python 3.10+ (используется только стандартная библиотека — `tkinter`).

```bash
python ca_watcher_gui.pyw
```

Или двойной клик по файлу, если `.pyw` ассоциирован с `pythonw.exe`.

## Источники данных

- `frontend-api-v3.pump.fun` — статус bonding curve
- Публичный RPC сети (Solana / Ethereum / BSC / Base / Arbitrum / Robinhood / ...)
- `api.dexscreener.com` — метаданные токена/пары после миграции на DEX
